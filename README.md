# Пятнашки

Реалистичная 3D-игра «15» в браузере. Работает как PWA: ставится на телефон или компьютер и играется офлайн.

- **Модели из Blender.** Скрипт `blender/build_puzzle.py` строит костяшки с настоящей гравировкой цифр (boolean, скругления рёбер, weighted normals) и рамки 3×3 / 4×4 / 5×5. Иконку рендерит Cycles.
- **Материалы.** PBR (`MeshPhysicalMaterial`), процедурные 3D-текстуры прямо в шейдере: дерево с годичными кольцами и порами, рамы «на ус», слоновая кость, каррарский мрамор, бархат. Затенение пазов (AO) и контактные тени считаются аналитически. Отражения идут от студийного окружения с софтбоксами.
- **Звук** синтезируется на лету. Удар костяшки собран из резонансов материала, у каждого набора свой тембр. Есть шорох скольжения, стерео-панорама по положению костяшки, реверберация комнаты, маримба на победу.
- **Анимации.** Скольжение с отскоком. При перемешивании костяшки взлетают и со стуком падают на новые места. При победе по доске проходит волна сальто. Есть параллакс от мыши и от наклона телефона.
- **Управление:** тап, перетаскивание пальцем (костяшку можно довести или отпустить), свайп, стрелки/WASD, `N` — новая партия.
- 4 набора, 3 размера поля, рекорды, автосохранение партии, вибрация.

## Запуск

```bash
npm install
npm run dev        # http://localhost:5173 (и адрес в локальной сети — чтобы открыть с телефона)
npm run build      # production-сборка в dist/ с service worker
npm run preview    # проверить сборку локально
```

PWA устанавливается только с HTTPS (или localhost), поэтому для телефона выложите `dist/` на любой статический хостинг: GitHub Pages, Netlify, Cloudflare Pages. Пути относительные, так что подпапка тоже подойдёт.

### Деплой на свой сервер

`npm run deploy` (или `sh deploy.sh`) собирает `dist/` и заливает его по SSH. Новая версия распаковывается в соседнюю папку и подменяет сайт переименованием, поэтому оборванная загрузка не ломает текущую версию. Адрес сервера задаётся переменной `DEPLOY_HOST=user@host` или строкой в файле `.deploy.env`, который не попадает в git. Папку сайта меняет `DEPLOY_SITE`, остальные параметры описаны в начале скрипта.

> Vite 6 выбран под Node 21. На Node ≥ 22.12 можно обновиться до Vite 8.

## Пересборка 3D-ассетов

Нужен Blender 5.x (путь к нему прописан в `package.json`):

```bash
npm run models     # public/models/puzzle.glb
npm run icons      # рендер иконки в Cycles + нарезка public/icons/*.png (нужен Python с Pillow)
```

Параметры костяшек (размер, фаска, глубина гравировки, шрифт) лежат в начале `blender/build_puzzle.py`. Шрифт по умолчанию — Bookman Old Style Bold из Windows. Другой шрифт передаётся вторым аргументом после `--`.

## Структура

| Файл | Что внутри |
| --- | --- |
| `src/stage.js` | рендерер, свет, окружение, камера, параллакс, твины, рендер по требованию и адаптивное разрешение |
| `src/materials.js` | процедурные материалы и наборы (темы) |
| `src/board.js` | доска: сборка из glTF, пикинг, анимации |
| `src/game.js` | правила, ввод, таймер, рекорды, сохранение |
| `src/puzzle.js` | чистая логика: ходы, решаемость, перемешивание |
| `src/audio.js` | синтез звука на Web Audio |
| `src/ui.js`, `src/style.css` | интерфейс |
